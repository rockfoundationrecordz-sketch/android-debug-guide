Wireless debugging, step by step

Pair your phone with a computer over Wi-Fi. No cable, no app to install. About two minutes.

Android 11 or newer · Samsung, Pixel, and most brands

Step 5 of 6

Get a pairing code

Tap Pair device with pairing code. A dialog shows a six-digit code plus an address like 192.168.1.50:37123. Leave it open. Codes expire in a few minutes.

Step 6 of 6

Pair from your computer

Type the code and address from the dialog into the fields below. Everything stays on this page, nothing is sent anywhere.

adb pair 192.168.1.50:37123

Run it, then enter the code when asked (or paste the full command). You should see Successfully paired.

Shown under the switch, not in the dialog.
adb connect 192.168.1.50:5555

Then check with adb devices. Your phone should be listed.

I don't have adb on the computer

Install Google's Platform Tools on the computer. On Windows, download the zip from developer.android.com, unzip it, and open a terminal in that folder. On macOS or Linux, use brew install android-platform-tools or your package manager.

Pairing failed or the code expired

Close the dialog and open Pair device with pairing code again. Use the newest code and the port from the dialog, not the port under the switch. Both the phone and the computer must be on the same network, and a VPN on either side can block the connection.

adb lists the phone as unauthorized

Tap Allow on the "Allow USB debugging?" prompt on the phone. If no prompt appears, revoke authorizations in Developer options and reconnect.

If a step doesn't work

I can't find a screen from the steps

Brands move and rename settings. About phone is the first item on Pixel and the last on Samsung and most others. The search icon at the top of Settings finds any screen by name, including wireless debugging and build number.

Wireless debugging keeps switching off

Android turns it off after a restart, and the pairing session ends when the dialog closes. Turn the switch on again and reopen the pairing dialog when needed.

The computer can't reach the phone

Check that both devices are on the same Wi-Fi and that the phone's screen is unlocked. Guest Wi-Fi networks and router settings that isolate clients block this kind of connection. Mobile hotspot works too if the computer joins it.
